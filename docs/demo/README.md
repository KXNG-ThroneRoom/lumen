# Lumen Demo Docs

This folder describes the current public demo path for Lumen.

The current public demo is a simplified controlled local demo backed by a local fixture, not a dense technical surface and not a live analysis product. It shows one contested start-date claim through four reader-facing tabs: Story, Evidence, Why uncertain, and Audit.

Core public claim:

> When does the regulation start?

Core explanation:

> Two sources disagree. A news report says June 1. An official filing says July 1. Lumen marks this as contested instead of guessing.

Use these docs to keep launch copy aligned with the runnable interface:

- `LOCAL_DEMO_WALKTHROUGH.md` — operator walkthrough for the simplified local demo.
- `../../apps/web/README.md` — frontend run instructions and UI boundary.

Public-demo boundary:

- controlled local fixture only;
- methods over conclusions;
- contested means unresolved for the reader, not automatically settled by software;
- no live ingestion, paid APIs, LLM calls, telemetry, accounts, or production coverage claim;
- no raw internal fingerprints, internal audit keys, source file names, underscore machine labels, or internal method labels as main UI promises.

Legacy/internal note: older panel component files may still exist for contract and honesty checks. They are not the current public launch UX.
